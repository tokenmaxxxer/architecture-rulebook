# arch-phase1-checklist

Owns exactly one methodology: the **repeated survey -> scout-brief ->
proposal procedure** for this role's phase-1 (기획서) work, as a
checklist artifact — not a gate, not a tool-use subagent.

See `agents/phase1-checklist.md` for the ordered steps. Documentation
only; no hook, no kill switch (nothing to disable).

## Relationship to the other plugins

The ordering and sourcing steps this checklist names are mechanically
enforced by `arch-sequence-gate` and `arch-citation-gate` respectively;
this plugin is the human-facing procedure those two gates mechanize, not
a duplicate of their logic.
